# Automobile MPG Data Analysis and Statistical Modeling

## Project Overview

This project performs statistical analysis and predictive modeling on the Automobile MPG dataset using Python in Google Colab.

The project explores the factors that affect fuel efficiency (MPG) through data cleaning, visualization, statistical analysis, hypothesis testing, correlation analysis, and linear regression modeling.

---

## Tools and Technologies

- Google Colab
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-Learn
- Statsmodels

---

## Dataset Features

The dataset contains automobile attributes such as:

- MPG (Miles Per Gallon)
- Cylinders
- Displacement
- Horsepower
- Weight
- Acceleration
- Model Year
- Origin

## Results

The analysis identifies the relationship between vehicle characteristics and fuel efficiency. Weight and horsepower are found to have a significant impact on MPG.

A linear regression model is built to predict fuel efficiency based on vehicle features.
